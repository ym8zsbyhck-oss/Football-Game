# Russian Football Career 2026 v1.1.0

Полный FLAT-проект для GitHub Pages.
Главная платформа: iPhone 16 Pro / Safari / landscape.

## Новое: FONBET Кубок России 2026/27

### Клубы РПЛ
В игре используются реальные группы Пути РПЛ сезона 2026/27:

Группа A:
- Спартак
- Рубин
- Оренбург
- Родина

Группа B:
- Краснодар
- Динамо Москва
- Ахмат
- Факел

Группа C:
- Зенит
- Балтика
- Крылья Советов
- Динамо Махачкала

Группа D:
- Локомотив
- ЦСКА
- Ростов
- Акрон

Каждая команда проводит 6 матчей.
Система очков:
- победа в основное время — 3;
- ничья + победа по пенальти — 2;
- ничья + поражение по пенальти — 1;
- поражение в основное время — 0.

1–2 места идут в верхнюю сетку.
3-е место продолжает турнир через нижнюю сетку / Путь регионов.
4-е место выбывает.

Добавлены:
- двухматчевые стадии Пути РПЛ;
- второй шанс через нижнюю сетку после поражения в верхнем пути;
- 1/8, 1/4 и 1/2 финала;
- единый финал Кубка России;
- серия пенальти при необходимости;
- трофей в истории карьеры.

### Первая лига / Вторая лига А
Карьера получает Путь регионов.
В игровой базе участвуют клубы, уже присутствующие в проекте.
Полная база Второй лиги Б и любительских команд пока не добавлялась.

## Новое: OLIMPBET Суперкубок России

В сезоне 2026 матч:
Зенит — Спартак.

Если карьера начата за один из этих клубов, матч можно сыграть самому.
Если основное время заканчивается вничью, дополнительного времени нет — сразу серия пенальти.

Для остальных клубов результат Суперкубка-2026 отображается в разделе «Турниры».

## Интерфейс
- новая вкладка «Турниры»;
- таблица группы Кубка России;
- история кубковых матчей;
