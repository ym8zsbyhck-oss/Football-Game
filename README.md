# Russian Football Career 2026 v1.0.2

Полный FLAT-проект для GitHub Pages.
Главная платформа: iPhone 16 Pro → Safari → горизонтальная ориентация.

## v1.0.2

### Розыгрыш с центра
- исправлена расстановка после гола;
- исправлена расстановка при начале первого и второго тайма;
- команда без мяча остаётся в своей половине и вне центрального круга;
- около мяча находятся только футболисты команды, выполняющей стартовый розыгрыш;
- после гола сбрасываются остаточная скорость, контакт, прессинг и старые action-state;
- выносливость после гола НЕ восстанавливается до 100%;
- второй тайм начинает противоположная стартовой команда независимо от количества голов.

### Ауты / рестарты
- новая безопасная state-machine аута;
- вбрасывающий напрямую подходит к линии без риска застрять в коллизии;
- каждый рестарт имеет watchdog;
- никакой аут/угловой/удар от ворот не может оставаться в restart-state бесконечно;
- если адресат недоступен, включается резервный безопасный ввод мяча;
- матч автоматически возвращается в phase=open.

### Удары и голы
- полевые игроки полностью игнорируются физикой УДАРА;
- они не могут остановить, поймать или перекрыть летящий удар;
- взаимодействовать с ударом может только вратарь;
- обычные передачи по-прежнему можно перехватывать;
- выбор точки удара ориентирован на свободную часть створа и позицию вратаря;
- исправлена критическая геометрия линии ворот:
  раньше мяч часто превращался в удар от ворот до пересечения линии гола;
  теперь гол фиксируется на передней линии ворот, совпадающей с рамкой/сеткой.

### ИИ — средний уровень
- ближайший AI-прессингующий действительно входит в отбор, а не просто стоит рядом;
- после неудачной попытки есть cooldown, поэтому нет бесконечного спама отбором;
- решения с мячом немного быстрее;
- атака активнее продвигается вперёд;
- AI лучше доходит до зоны удара;
- примерно сохраняется умеренное число попыток, без 30–40 ударов за матч;
- рейтинги клубов и FC-IQ/RPL-профили продолжают влиять на качество игры.

### Вратарь
- вратарь по-прежнему умеет SET / ADJUST / READY / DIVE / SAVE / 1V1;
- он немного слабее, чем раньше;
- реакция не мгновенная;
- прыжок и зона сейва уменьшены;
- сильный/краевой удар может пройти даже рядом с вратарём;
- при контакте с мячом сейв больше не гарантирован на 100%;
- хороший рейтинг вратаря всё ещё даёт преимущество.

### Сохранено
- 5×5;
- FC-IQ роли;
- BUILD_UP / PROGRESS / FINAL_THIRD / CHANCE;
- COUNTER_PRESS / DEFENSIVE_SHAPE;
- dribble touches;
- first touch;
- физические дуэли;
- анимации круглых игроков и мяча;
- сетка ворот;
- карьера;
- сохранения;
- РПЛ / Первая лига / Вторая лига А;
- таблица и календарь;
- два тайма и добавленное время;
- экран перерыва и статистика;
- МАТЧ! / ПРЯМОЙ ЭФИР;
- iPhone 16 Pro Safari safe-area / visualViewport.
