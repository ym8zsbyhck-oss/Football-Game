# Russian Football Career 2026 v0.6.1 — Match Fix

FLAT-версия без папок для GitHub Pages.

Главные исправления:
- старт матча строго с центрального круга;
- реальный короткий розыгрыш мяча с центра;
- после гола новый розыгрыш с центра;
- передача больше не может мгновенно прилипнуть обратно к пасующему;
- мяч физически появляется перед ногой игрока и летит по полю;
- партнёр или соперник должен реально коснуться мяча, чтобы получить владение;
- более плавное ускорение и торможение игроков;
- устранено постоянное дёргание к мячу;
- только один игрок активно прессингует;
- второй игрок страхует;
- остальные сохраняют компактную позиционную структуру;
- ИИ с мячом умеет вести, пасовать, отдавать вразрез и бить;
- крайние игроки дают ширину;
- нападающий держит глубину и делает забегания;
- вратарь имеет отдельную логику;
- ауты, угловые и удары от ворот сохранены.
