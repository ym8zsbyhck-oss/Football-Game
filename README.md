## Табло сезона 2026/27

Для матчей чемпионата теперь используются разные broadcast scorebugs:

- Альфа-Банк РПЛ — тёмно-индиговое табло с красным акцентом нового титульного партнёра;
- Лига PARI — чёрно-мятная графика в текущем стиле PARI;
- LEON-Вторая Лига А — чёрно-красная графика LEON;
- FONBET Кубок России — отдельная оранжевая кубковая графика;
- OLIMPBET Суперкубок России — отдельная золотая графика.

Табло автоматически выбирается по соревнованию. Кубковый матч больше не выглядит как матч РПЛ/ФНЛ.

В scorebug входят:
- сокращения клубов;
- эмблемы клубов;
- счёт;
- игровой таймер;
- название и сезон соревнования;
- цветовая полоска каждого клуба.

Расположение перенесено ближе к телевизионной логике — компактно в верхнюю левую часть, при этом кнопка паузы и safe-area iPhone не перекрываются.
