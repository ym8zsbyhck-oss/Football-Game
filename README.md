# Russian Football Career 2026 v0.6.2 — Contact Fix

Исправлено дрожание игроков при столкновениях.

Новая система:
- союзники заранее расходятся и не занимают одну точку;
- круги физически не могут оставаться внутри друг друга;
- при столкновении соперников с мячом начинается единичная силовая дуэль;
- успешная дуэль выбивает мяч в свободное пространство;
- при неудачной попытке владелец мяча проходит дальше по касательной;
- соперники без мяча обходят/расталкиваются, вместо бесконечного движения друг в друга;
- контакт имеет cooldown, поэтому отбор не пересчитывается 60 раз в секунду;
- сохранены реальные передачи, старт с центра, ауты, угловые и удары от ворот.
