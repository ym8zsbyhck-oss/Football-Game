# Russian Football Career 2026 v0.6

Полная многфайловая версия под Vercel/GitHub Pages.

## Состав проекта
- index.html
- css/app.css
- js/data.js — клубы и дивизионы на август 2026
- js/logos.js — загрузка настоящих эмблем через Wikimedia/Wikipedia API
- js/career.js — карьера, календарь, таблица
- js/match.js — 11×11 и матч-движок
- js/app.js — интерфейс и iPhone-управление
- manifest.webmanifest
- sw.js

## ИИ
Модель поведения вдохновлена официально описанными принципами EA SPORTS FC 26 Authentic Gameplay / FC IQ, но это собственная реализация, а не код EA.

## Эмблемы
Логотипы не рисуются вручную. Во время запуска игра запрашивает thumbnail клубной страницы через Wikipedia/Wikimedia API. Поэтому для эмблем нужен интернет.
