- shielding и физические дуэли;
- отбор зависит от угла, скорости, силы и рейтинга;

- анимации READY / DIVE / CATCH / PARRY вратаря;
- вращение текстуры мяча;
- разные профили всех 16 клубов РПЛ;
- сохранены 5×5, карьера, рейтинги, ауты, угловые, удар от ворот, перерыв, статистика, МАТЧ! ТВ.
