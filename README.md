# РПЛ Football 2026 — HTML-прототип

## Запуск
Откройте `index.html` в браузере. На iPhone лучше открыть через опубликованный сайт и повернуть телефон горизонтально.

## Управление
- Левая половина экрана: коснитесь и двигайте палец — виртуальный джойстик.
- ПАС: передача ближайшему партнёру.
- УДАР: удар в сторону ворот.
- РЫВОК: удерживайте для ускорения.
- СМЕНА: выбрать ближайшего к мячу игрока.
- Матч длится 4 реальные минуты и имитирует 90 игровых минут.

## Публикация на GitHub Pages
1. Создайте новый публичный репозиторий.
2. Загрузите `index.html`.
3. Settings → Pages → Deploy from a branch → main / root.
4. Откройте выданную ссылку на iPhone.
5. Safari → Поделиться → На экран «Домой».

## Примечание
Эмблемы загружаются из Wikimedia. Если интернет недоступен или ссылка не сработала, автоматически появится цветная эмблема с сокращением клуба.
Списки игроков в этом прототипе — компактная игровая база и могут редактироваться внутри массива CLUBS в index.html.
