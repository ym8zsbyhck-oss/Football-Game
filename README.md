# Russian Football Career 2026 v0.7 — 5x5 Mobile Rework

Главные изменения:
- матч теперь 5×5: 1 вратарь + 4 полевых игрока;
- команды больше не бегают толпой;
- сила паса регулируется удержанием кнопки ПАС;
- сила удара регулируется удержанием кнопки УДАР;
- при владении мячом нельзя переключиться на другого игрока;
- в левом нижнем углу: имя, номер и выносливость управляемого игрока;
- в правом нижнем углу: данные собственного вратаря;
- вратарь стал сильнее: выше радиус реакции, позиционирование и шанс сейва;
- аут выполняет реальный игрок: он идёт к линии и вбрасывает мяч;
- угловые и удары от ворот сохранены;
- рейтинг клуба влияет на точность передач, ударов, отбор, силу ИИ и вратаря;
- высокий рейтинг = сильнее команда, низкий = слабее.
