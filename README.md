# Russian Football Career 2026 v0.8.2 — iPhone 16 Pro Safari Edition

Полный FLAT-проект без папок для GitHub Pages.

## Главная целевая платформа
- iPhone 16 Pro
- Safari
- горизонтальная ориентация
- запуск прямо из Safari, не только PWA

## Что исправлено в v0.8.2
- интерфейс рассчитывается по реальному `visualViewport` Safari;
- изменение высоты из-за верхней/нижней панели Safari больше не должно ломать HUD;
- учтены safe-area / Dynamic Island / скругления экрана;
- игровое поле масштабируется при изменении доступного viewport без сброса матча;
- кнопки управления уменьшены и переставлены под высоту iPhone 16 Pro;
- панели игроков не перекрывают правые кнопки;
- экран перерыва подогнан под фактическую высоту Safari;
- главное меню и карьера также используют фактическую доступную высоту;
- отключены нежелательные pinch/gesture/touch-scroll во время матча;
- сохранены все возможности v0.8.1.
