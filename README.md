# Russian Football Career 2026 v1.1.4 — 3 Career Slots

Полный FLAT-проект.
Главная платформа: iPhone 16 Pro / Safari / landscape.

## Три карьеры одновременно

Теперь доступны 3 независимых слота сохранений.

Можно, например:
- Слот 1 — Зенит;
- Слот 2 — Спартак;
- Слот 3 — клуб Первой или Второй лиги.

Каждая карьера отдельно хранит:
- клуб;
- таблицу;
- тур;
- календарь;
- результаты;
- Кубок России;
- Суперкубок;
- трофеи;
- прогресс сезона.

## Главное меню

Над выбором клубов отображаются три компактных слота.

Заполненный слот показывает:
- номер слота;
- эмблему;
- название клуба;
- лигу;
- текущий тур;
- кнопку ИГРАТЬ;
- кнопку удаления ×.

Новая карьера автоматически занимает первый свободный слот.
Если заполнены все 3 — начать четвёртую нельзя, пока один слот не будет удалён.

## Старые сохранения

Одиночное сохранение из v1.1.3 и более ранних версий автоматически переносится в СЛОТ 1.
Оно не теряется.

## Автосохранение

Когда открыт слот, все дальнейшие сохранения и результаты пишутся только в него.
Другие две карьеры не изменяются.

Все функции v1.1.3 сохранены:
- тайм 60 секунд активной игры;
- запуск времени после передачи с центра;
- Team IQ;
- Кубок России;
- Суперкубок России;
- РПЛ / Первая лига / Вторая лига А;
- FC-IQ;
- 5×5;
- сетка ворот;
- МАТЧ! прямой эфир.
