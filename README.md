# Russian Football Career 2026 v1.1.5

Полный FLAT-проект.

## Исправление старта карьеры ФНЛ 1 / ФНЛ 2

Причина бага была в создании Кубка России.

Для клуба РПЛ `Career.new()` создавал групповую стадию Кубка без немедленного
поиска соперника, поэтому карьера запускалась нормально.

Для клуба Первой или Второй лиги Путь регионов сразу пытался подобрать
кубкового соперника через `Career.club()`. В этот момент новая `Career.state`
ещё не была полностью присвоена, поэтому создание карьеры прерывалось.

### Исправлено
- базовое состояние карьеры теперь создаётся первым;
- затем создаётся Кубок России;
- затем Суперкубок;
- первый соперник Пути регионов получает выбранный клуб напрямую;
- добавлена защита от отсутствующего клуба/дивизиона;
- неудачное создание не оставляет повреждённый занятый слот.

Проверено отдельно:
- РПЛ;
- Первая лига;
- Вторая лига А — Золото;
- Вторая лига А — Серебро;
- три независимых слота сохранений.

Все функции v1.1.4 сохранены:
3 карьеры, Team IQ, Кубок России, Суперкубок, 60 секунд на тайм,
таймер после ввода мяча, FC-IQ, 5×5 и остальная механика.
