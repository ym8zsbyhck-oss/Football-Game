# Russian Football Career 2026 v1.3.0 — Internet Broadcast Visuals

Полный FLAT-проект для GitHub Pages.

## Главное визуальное обновление

### Стадион вокруг поля
Матч больше не выглядит как поле на сплошном зелёном фоне.
Поле находится внутри отдельной телевизионной рамки стадиона, а вокруг него показываются трибуны/арена.

При запуске матча игра автоматически ищет фотографию стадиона домашнего клуба через интернет:
1. Wikimedia Commons;
2. русскую Wikipedia;
3. если подходящее изображение не найдено — используется локальный тёмный stadium fallback, игра не ломается.

Удачный URL арены кэшируется в localStorage, поэтому при следующем матче за этот клуб не требуется повторный глубокий поиск.

### Оригинальные изображения турниров в матчевом табло
Табло больше не использует только нарисованные буквами заглушки.
Оригинальный графический знак соревнования загружается через интернет.

Используются отдельные источники для:
- Альфа-Банк РПЛ 2026/27;
- Лиги PARI;
- LEON-Второй лиги А;
- FONBET Кубка России;
- OLIMPBET Суперкубка России.

Если удалённая картинка временно недоступна, автоматически показывается текстовый fallback текущего турнира.

### Рекламная кромка поля
Верхняя и нижняя кромка поля используют графику текущего соревнования, поэтому оформление визуально меняется вместе с турниром.

### Клубные эмблемы
Как и раньше, эмблемы клубов ищутся через Wikidata / Wikipedia / Wikimedia Commons и кэшируются.

## Важно
Интернет-картинки не зашиты в ZIP как поддельные или перерисованные изображения — браузер загружает их с исходных интернет-адресов. Поэтому при полном отсутствии интернета игра работает, но использует fallback без фотографии стадиона и без удалённого знака турнира.

Все функции v1.2.2 сохранены:
- реалистичный баланс счетов;
- режим тренера;
- Team IQ;
- три карьеры;
- Кубок России и Суперкубок;
- РПЛ / Первая лига / Вторая лига А;
- 60 секунд активной игры на тайм;
- МАТЧ! прямой эфир.
